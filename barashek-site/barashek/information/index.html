Информация о макете

О макете

«Барашек» — локальная демонстрационная версия дизайна сайта lavash26.ru, подготовленная по запросу пользователя. Это не официальный сайт ресторана и не предложение услуг.

Что работает

Страницы ресторана, навигация, прокрутка с барашком, просмотр меню, фотогалерея и проверка полей формы бронирования. Шрифты и фотографии хранятся локально. Скачать исходные PDF-меню можно на странице меню.

Ограничения

Бронирование не отправляется, оплата и доставка не подключены. Контактные данные и сведения о заведении перенесены из референса для воспроизведения макета. Видео-фон заменён статичной фотографией; вместо 3D-тура доступна фотогалерея. Интерактивная карта не подключена.

Права на материалы

Переименование сайта не отменяет авторские права. Фотографии, шрифты, графика, исходные PDF и элементы дизайна принадлежат соответствующим правообладателям. Лицензия на их использование не проверялась. До публичного или коммерческого размещения получите разрешение либо замените материалы на лицензированные. PDF-файлы содержат оригинальное оформление и название ресторана.

Персональные данные

Поля демонстрационной формы проверяются только в браузере. Макет не отправляет заявки на сервер ресторана и не сохраняет введённые контакты. Аналитика исходного сайта удалена.

Запуск

Откройте index.html в корне папки barashek. Для локального HTTP-просмотра запустите: python -m http.server 8080 --bind 127.0.0.1 --directory barashek.
